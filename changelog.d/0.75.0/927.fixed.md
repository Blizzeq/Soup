- **Layer streaming's disk tier no longer reads on the compute thread (#927).** `stream_source: disk` (and `auto` when the base does not fit RAM) used to call a synchronous, memory-mapped read from the thread that was supposed to be feeding the GPU, so every byte arrived through page faults while the card idled. The base now streams through a background reader that parses each shard's header itself — no memory map, so nothing charges commit for the whole file — and stages layers into pinned host memory. Measured on one box (RTX 5070 Laptop, Windows, NVMe; [record](benchmarks/gate-927-async-nvme-source.md)) against a **same-day control of the source it replaces**, cold on a 36 GB 70B-shaped NF4 store larger than RAM at batch 1 × seq 512: **92–100 s per step became 30–48 s (2.1–3.1×)**, 5.1 → 16.9 tok/s, 0.70 → 2.32 GB/s at the source, with peak VRAM unchanged at 4.38 GB and the GPU leaving idle clocks on this tier for the first time (180 MHz for a whole control block, against 1417–2355 MHz). It is still bound by the read: per-layer read brackets are 90–93% of the step. **Warm, with the whole store in the page cache, it is a 1.19× REGRESSION** (1.84 s against 1.54 s) — with the store cached a synchronous read is close to a `memcpy`, so there is nothing for a reader to hide; if the store fits RAM the RAM tier is 1.9–2.2× faster than either disk arm and is what `auto` already picks. New `training.stream_read_ahead` (default 2, range 1–8) sets the reader's depth, where **a setting of N stages N−1 layers ahead** because one slot is always held by the layer being consumed, and each level costs one layer of pinned host RAM (1.5 GB at depth 1, 2.0 at 2, 2.8 at 4 on a 70B). No depth was distinguishable on throughput in that record once run order was controlled for, so treat it as a host-memory knob. A non-default `stream_read_ahead` beside `stream_source: ram` is **refused** rather than accepted and ignored: the reader belongs to the NVMe tier and `ram` never falls back to it. The default is accepted, because a default is not a decision.
