- **An unregistered `data.chat_template` name exits with a message instead of a `KeyError` traceback (by @Blizzeq in #1175).**
  `soup data preprocess` and `soup train` now print `Invalid data.chat_template`
  with the known template names and exit 1. `soup train` checks the name right
  after loading the config, so a typo no longer surfaces only after the model has
  been downloaded and loaded.
